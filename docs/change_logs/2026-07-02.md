# 2026-07-02 修改日志

分支：`exp/semantic-v2`  
提交：`c799dc85 Add observable dynamic SafeStride probe`

## 1. 拆分 SafeStride 标签有效性

- 改动：新增 `minimum_safe_stride_interval_valid`。首次 entry riser 和
  rear-partial 只提供 lower 监督；只有后续 expected-riser 证据确认后，才监督
  upper 和 width。
- 目的：避免要求网络在只接触第一条立面时猜测尚不可观测的 tread depth 和完整
  安全区间。
- 关键位置：
  `temporal_stair_rewards.py`、`stair_geometry.py`、`observations.py`。
- 接口：`latent_labels` 从 15 维增至 16 维；新增维度仅为训练期 privileged
  label，不进入部署 observation。

## 2. SafeStride 改为快慢时间尺度解码

- 改动：动态 lower decoder 读取 `LSTM h_t + slow shape memory 8维 +
  deployable gait phase 2维`；独立 width decoder 只读取 slow shape memory。
- 目的：让当前脚位、目标脚切换和步态相位影响每一步 lower，同时让楼梯几何
  width 保持慢速稳定。
- 关键位置：`src/mjlab/rl/slow_latent_model.py`。
- 约束：输出仍满足 `upper >= lower`；没有硬编码“下一步增加几厘米”。
- 修正：动态 width 的迁移初值设在 sigmoid 可学习区，避免接近零宽度时梯度
  饱和。

## 3. 新增隔离的 SafeStride 可学习性实验

- 新任务：
  `Mjlab-Velocity-Blind-Rough-TargetNavigation-SemanticV2SafeStrideProbe-Unitree-G1`。
- 改动：只优化 `safe_stride_head` 和 `safe_stride_width_head`；冻结 actor、
  critic、LSTM/backbone、其他 heads 和全部 normalization buffers。
- 目的：先回答“固定旧本体历史中是否存在足够信息让 SafeStride 学好”，避免
  PPO 策略漂移干扰判断。
- 保护：每次 update 后检查除两个 SafeStride decoder 外的完整 state 是否位级
  不变。
- 起点：从旧 `model_51000.pt` bootstrap，不恢复旧 optimizer 和 iteration。

## 4. 补充指标和兼容迁移

- 指标：区分 center 是否落入目标区间，与真实 interval overlap、target
  coverage、IoU；新增 lower/upper/width/center 的 update-global 均值、标准差、
  correlation、R²、MAE 和 signed error。
- 兼容：旧 91 维 latent checkpoint 可迁移到带 gait phase 的 93 维输入；旧
  SafeStride 权重可严格加载到动态 decoder。
- ONNX：外部 SafeStride 标量输出仍为 interval center，现有接口未增加输出项。
