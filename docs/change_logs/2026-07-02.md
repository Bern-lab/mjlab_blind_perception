# 2026-07-02 修改日志

分支：`exp/semantic-v2`  
提交：`c799dc85 Add observable dynamic SafeStride probe`

## 1. 拆分 SafeStride 标签有效性

- 改动：新增 `minimum_safe_stride_interval_valid`。首次 entry riser 和
  rear-partial 只提供 lower 监督；只有后续 expected-riser 证据确认后，才监督
  upper 和 width。
- 目的：避免要求网络在只接触第一条立面时猜测尚不可观测的 tread depth 和完整
  安全区间。
- 关键位置：
  `temporal_stair_rewards.py`、`stair_geometry.py`、`observations.py`。
- 接口：`latent_labels` 从 15 维增至 16 维；新增维度仅为训练期 privileged
  label，不进入部署 observation。

## 2. SafeStride 改为快慢时间尺度解码

- 改动：动态 lower decoder 读取 `LSTM h_t + slow shape memory 8维 +
  deployable gait phase 2维`；独立 width decoder 只读取 slow shape memory。
- 目的：让当前脚位、目标脚切换和步态相位影响每一步 lower，同时让楼梯几何
  width 保持慢速稳定。
- 关键位置：`src/mjlab/rl/slow_latent_model.py`。
- 约束：输出仍满足 `upper >= lower`；没有硬编码“下一步增加几厘米”。
- 修正：动态 width 的迁移初值设在 sigmoid 可学习区，避免接近零宽度时梯度
  饱和。

## 3. 新增隔离的 SafeStride 可学习性实验

- 新任务：
  `Mjlab-Velocity-Blind-Rough-TargetNavigation-SemanticV2SafeStrideProbe-Unitree-G1`。
- 改动：只优化 `safe_stride_head` 和 `safe_stride_width_head`；冻结 actor、
  critic、LSTM/backbone、其他 heads 和全部 normalization buffers。
- 目的：先回答“固定旧本体历史中是否存在足够信息让 SafeStride 学好”，避免
  PPO 策略漂移干扰判断。
- 保护：每次 update 后检查除两个 SafeStride decoder 外的完整 state 是否位级
  不变。
- 起点：从旧 `model_51000.pt` bootstrap，不恢复旧 optimizer 和 iteration。

## 6. 首轮 500 轮 Probe 结果

- 结果：动态 lower 可学；最近 100 轮 global lower correlation 约 0.53、
  R² 约 0.22。
- 失败项：width correlation 约 0.16、R² 约 -2.45、MAE 约 8 cm，完整区间
  不可用。
- 诊断：width 并非固定输出，而是在补偿 interval-valid 子集中的 lower 偏差；
  原实现通过 upper 间接监督 width，且 lower/upper 共用分母。
- 决策：停止原 loss 续训；`model_499.pt` 仅保留为诊断 checkpoint。

## 7. SafeStride direct-width v2

- 可观测性：只有撞到 `layer >= 2` 的 expected riser 才产生一次 depth
  confirmation；layer1 重复碰撞和普通 tread 接触只监督 lower。
- 几何 mask：lower-valid 与完整 interval-valid 分离，并增加单帧 depth
  confirmation label。`latent_labels` 从 16 维增至 17 维，新增项仍仅用于训练。
- 参数化：动态 width 改为独立绝对物理宽度，不再乘
  `(safe_stride_max - predicted_lower)`；upper 由 `lower + width` 派生。
- Loss：lower 和 width 分别按各自 valid mask 独立归一化；直接监督 width，
  upper 不再参与回归。
- 诊断：新增 interval-valid 子集 lower 统计、width bias、upper 越界率、
  interval-valid frame count 和 unique depth-confirmation count。
- 验证：124 项定向测试、Ruff、ty、pyright 通过；旧 `model_51000.pt`
  成功加载并完成单迭代 Probe smoke，冻结状态保持 bit-exact。

## 8. Frozen-latent geometry Probe

- 新任务：
  `Mjlab-Velocity-Blind-Rough-TargetNavigation-SemanticV2GeometryProbe-Unitree-G1`。
- Probe 直接回归 tread depth 和 riser height，不再用 SafeStride width
  间接判断几何是否存在。
- 输入可通过 `geometry_probe_input` 切换为 `shape`、`hidden` 或
  `combined`；actor、critic、LSTM、latent memory、旧 heads 和 normalization
  均保持位级冻结。
- 20% environment 固定为 validation，不参与梯度；depth 样本只在
  confirmation age 0、1、4、8、16、32 取样，避免持续帧重复主导 loss。
- update-global 指标按 train/validation、confirmation age 和八档 tread depth
  分组汇总 correlation、R²、MAE、bias 和预测/标签标准差。
- 可选 `geometry_probe_permute_depth_labels` 使用确定性错配 depth 标签训练，
  作为排除固定均值和伪相关的 null control。
- 新增相邻层双脚稳定支撑的水平/竖直脚距证据统计，以及每档 depth 的
  confirmation 数量、wrong-layer candidate 和重复 expected-riser 计数。
- `latent_labels` 从 17 维增至 23 维；新增 validation mask、confirmation
  age 和相邻层双脚 evidence 都是训练期诊断标签，不进入部署 observation。

## 9. Stage 0 sequence/event 统计

- 新增 reward-neutral `stair_sequence_event_logger` metrics term，不修改 actor、
  reward 数值或网络结构。
- 新增 `MJLAB_STAIR_EXPORT_DIR` 可选导出开关；启用后生成
  `stair_sequences.csv` 和 `stair_events.csv`，默认关闭磁盘与 CPU 导出。
- 关键事件采用 rising edge，并按 sequence 保证一次最终记录；持续接触帧不再
  被当作独立事件。
- confirmation detector 继续使用 blocked-riser 条件；独立 oracle 改用原始
  expected-riser 竖直面接触，因此 precision、recall、missed 和 delay 不再由
  同一条件自我验证。
- 新增 confirmation precision、recall、layer1/wrong-layer/wrong-sequence/flat
  false、duplicate、missed、delay mean/std 及有效计数。
- duplicate 收紧为同一 sequence 的同一 layer 再次触发；后续不同 layer
  作为新的几何证据单独记录为 ``confirmation_new_layer``，不再污染
  duplicate ratio。
- 当前只完成 Stage 0；尚未生成 Stage 1 depth interval，也未修改 SafeStride。
